# MySQL legado

Este diretório guarda scripts, JSONs e consultas antigas da fase MySQL do projeto.

O banco ativo do NossoZelo agora é PostgreSQL. Para ambientes atuais, use os schemas e migrations Prisma em:

- `server/prisma/schema.prisma`
- `server/prisma/migrations/`
- `controlador/prisma/schema.prisma`
- `controlador/prisma/migrations/`

Os arquivos daqui servem apenas para consulta histórica.
